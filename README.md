# 🧠 MindMate — AI Wellness Companion

> **Your everyday AI companion for mental wellness, reflection, and healthier habits.**

MindMate is an AI-powered wellness companion designed to help users understand their emotions, reflect through journaling, track their mood, and build healthier daily habits — all in one simple and supportive interface.

## ✨ Features

* 🤖 **AI Wellness Chat** — Talk with an AI companion and receive supportive responses.
* 😊 **Mood Tracker** — Record your daily mood and view your mood history.
* 📊 **Wellness Dashboard** — Get a simple overview of your wellness activity.
* 📔 **Digital Journal** — Write and save personal reflections.
* 🧘 **Wellness Toolkit** — Access simple wellness and self-care activities.
* 🎙️ **Voice Interaction** — Speech recognition and voice output for a more interactive experience.
* 💬 **Conversation Memory** — Keep track of conversations for a more continuous experience.
* 🌙 **Modern Responsive UI** — Clean interface designed for desktop and mobile screens.
* 🔒 **Local Data Storage** — Mood and journal data can be stored locally in the browser.

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/roshaniwani8/Mindmate-hackathon-2026-.git
cd Mindmate-hackathon-2026-
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it:

**Windows**

```bash
venv\Scripts\activate
```

**macOS/Linux**

```bash
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the Flask server

```bash
python app.py
```

Then open the local URL shown by Flask in your browser.

## 💡 Why MindMate?

Mental wellness can be difficult to manage when people don't have an easy way to pause, reflect, and understand how they're feeling.

MindMate brings several small wellness tools together with an AI companion to make everyday emotional reflection more accessible and approachable.
